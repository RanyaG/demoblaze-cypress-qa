# A11Y-004: Contraste de cor insuficiente em preços, botões e títulos dos modais

| Campo | Valor |
|---|---|
| Impacto (axe-core) | Sério |
| Prioridade | Média |
| Status | Aberto |
| Critério WCAG | 1.4.3 Contraste mínimo (nível AA) |
| Regra do axe | [color-contrast](https://dequeuniversity.com/rules/axe/4.14/color-contrast) |
| Telas afetadas | Todas as auditadas, menos o modal de finalização do pedido (30 elementos) |
| Ambiente | demoblaze.com, Chrome, auditoria automática (AC-01 a AC-06) |

## Passos para reproduzir

1. Rodar `npm run test:a11y`, ou abrir a página com a extensão axe DevTools e executar a análise.
2. Ver os elementos apontados pela regra `color-contrast`.

## Resultado esperado

Texto normal com contraste de pelo menos **4,5:1** em relação ao fundo, e texto grande (a partir de 18 pt, ou 14 pt em negrito) com pelo menos **3:1**.

## Resultado obtido

| Tela | Elementos | Exemplo |
|---|---|---|
| Página inicial | 18 | Preço dos produtos nos cards (`.card-block > h5`) |
| Página de produto | 1 | Botão verde **Add to cart** (`.btn-success`) |
| Carrinho | 1 | Botão verde **Place Order** (`.btn-success`) |
| Modal de login | 3 | Título do modal (`#logInModalLabel`) |
| Modal de cadastro | 3 | Título do modal (`#signInModalLabel`) |
| Modal de contato | 4 | Título do modal (`#exampleModalLabel`) |

Pessoas com baixa visão, daltonismo ou usando o celular sob luz forte podem não conseguir ler esses textos, entre eles o **preço** e o **botão de compra**, que são essenciais para comprar.

## Sugestão de correção

Escurecer as cores do texto ou do fundo até atingir 4,5:1, conferindo com uma ferramenta de contraste (WebAIM Contrast Checker ou o próprio axe DevTools). No botão verde, por exemplo, um tom de verde mais escuro com texto branco resolve.
