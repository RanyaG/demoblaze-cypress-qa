# A11Y-002: Links sem nome acessível nos cards de produto

| Campo | Valor |
|---|---|
| Impacto (axe-core) | Sério |
| Prioridade | Alta |
| Status | Aberto |
| Critérios WCAG | 2.4.4 Finalidade do link (nível A) e 4.1.2 Nome, função, valor (nível A) |
| Regra do axe | [link-name](https://dequeuniversity.com/rules/axe/4.14/link-name) |
| Telas afetadas | Página inicial (9 links) e página de produto (2 links) |
| Ambiente | demoblaze.com, Chrome, auditoria automática (AC-01 e AC-02) |

## Passos para reproduzir

1. Abrir a página inicial com um leitor de tela (NVDA) ligado, ou rodar `npm run test:a11y`.
2. Navegar pelos links da lista de produtos com a tecla `Tab`.

## Resultado esperado

Cada link tem um nome que diz para onde ele leva, por exemplo "Samsung galaxy s6".

## Resultado obtido

Os 9 links das imagens dos produtos na página inicial não têm nome acessível. Exemplo:

```
.card.h-100 > a[href="prod.html?idp_=1"]
```

O leitor de tela anuncia só "link", sem dizer qual é o produto. Como cada card tem dois links (a imagem e o título), quem navega com teclado passa por 9 links "vazios" na página. Na página de produto, o axe encontrou mais 2 links sem nome (exemplo: `.left`).

## Sugestão de correção

Dar um nome a esses links: colocar o `alt` com o nome do produto na imagem dentro do link. Outra opção é tirar o link da imagem do caminho do teclado (`tabindex="-1"` e `aria-hidden="true"`), já que o título do card leva para a mesma página.
