# BUG-008: Preço do produto sem marcação semântica na listagem

| Campo | Valor |
|---|---|
| Prioridade | Baixa |
| Status | Aberto |
| Módulo | Catálogo (HTML) |
| Ambiente | demoblaze.com, Chrome |
| Caso de teste | CT-1.1 / T01 |

## Passos para reproduzir

1. Abrir a página inicial.
2. Inspecionar o preço de um card de produto.

## Resultado esperado

O preço fica num elemento próprio (como o `.price-container` da página do produto), fácil de localizar por testes e leitores de tela.

## Resultado obtido

O preço está num `<h5>` genérico. A funcionalidade funciona, mas o teste que buscava `.price-container` na listagem falhou.


## Sugestão de correção

Usar a mesma marcação da página do produto ou um `data-testid` para o preço.
