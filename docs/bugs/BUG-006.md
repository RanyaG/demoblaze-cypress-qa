# BUG-006: Compra permitida sem login

| Campo | Valor |
|---|---|
| Prioridade | Média |
| Status | Aberto |
| Módulo | Finalização de compra |
| Ambiente | demoblaze.com, Chrome |
| Caso de teste | CT-4.1 / T06 |

## Passos para reproduzir

1. Sem fazer login, adicionar um produto ao carrinho.
2. Finalizar a compra.

## Resultado esperado

O sistema pede login antes de concluir a compra.

## Resultado obtido

A compra é concluída sem usuário autenticado.


## Sugestão de correção

Exigir login (ou um checkout de visitante com e-mail) antes da confirmação.
