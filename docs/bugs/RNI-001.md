# RNI-001: Não existe busca de produtos

| Campo | Valor |
|---|---|
| Tipo | Requisito não implementado |
| Prioridade | Alta |
| Módulo | Catálogo |
| Caso de teste | CT-1.2 e CT-1.3 / T02 |

## O que a especificação pede

A história de usuário US1 prevê uma barra de busca: ao pesquisar "Phone", o sistema lista os produtos relacionados; ao pesquisar um termo sem resultado, mostra "No products found matching your search".

## O que o sistema faz

Não há campo de busca na página. O teste falhou ao procurar o elemento `#search_box`.


## Impacto

Com 15 produtos o impacto ainda é pequeno, mas a navegação depende só das três categorias. Num catálogo maior, a falta de busca prejudica a conversão.
