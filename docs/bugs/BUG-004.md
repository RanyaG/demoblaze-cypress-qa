# BUG-004: Não há controle de estoque

| Campo | Valor |
|---|---|
| Prioridade | Alta |
| Status | Aberto |
| Módulo | Estoque e finalização de compra |
| Ambiente | demoblaze.com, Chrome |
| Caso de teste | CT-4.5 / T09 |

## Passos para reproduzir

1. Dois usuários adicionam o mesmo produto ao carrinho.
2. O primeiro finaliza a compra.
3. O segundo finaliza a compra.

## Resultado esperado

Com estoque de 1 unidade, só a primeira compra é aprovada; a segunda recebe "Produto esgotado".

## Resultado obtido

As duas compras são aprovadas. O sistema não controla estoque.


## Sugestão de correção

Reservar ou baixar o estoque na finalização do pedido, com verificação no servidor.
