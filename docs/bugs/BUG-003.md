# BUG-003: Cartão de crédito aceita letras e símbolos

| Campo | Valor |
|---|---|
| Prioridade | Alta |
| Status | Aberto |
| Módulo | Finalização de compra |
| Ambiente | demoblaze.com, Chrome |
| Caso de teste | CT-4.4 / T08 |

## Passos para reproduzir

1. Adicionar um produto ao carrinho.
2. Clicar em **Place Order**.
3. Preencher os campos e, em **Credit card**, digitar `1234 ABCD !@#$`.
4. Clicar em **Purchase**.

## Resultado esperado

Mensagem "O campo do cartão deve conter apenas números" e a compra não é concluída.

## Resultado obtido

A compra é confirmada e o número inválido aparece na confirmação.


## Sugestão de correção

Aceitar só dígitos, validar o tamanho do número e conferir o dígito verificador (algoritmo de Luhn).
