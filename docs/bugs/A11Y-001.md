# A11Y-001: Imagens do cabeçalho sem texto alternativo

| Campo | Valor |
|---|---|
| Impacto (axe-core) | Crítico |
| Prioridade | Alta |
| Status | Aberto |
| Critério WCAG | 1.1.1 Conteúdo não textual (nível A) |
| Regra do axe | [image-alt](https://dequeuniversity.com/rules/axe/4.14/image-alt) |
| Telas afetadas | Página inicial, página de produto e carrinho (2 imagens em cada) |
| Ambiente | demoblaze.com, Chrome, auditoria automática (AC-01, AC-02 e AC-03) |

## Passos para reproduzir

1. Abrir a página inicial com um leitor de tela (NVDA) ligado, ou rodar `npm run test:a11y`.
2. Navegar até o logo no topo da página.

## Resultado esperado

Toda imagem informativa tem um texto alternativo (`alt`) que descreve o conteúdo, por exemplo `alt="PRODUCT STORE"` no logo. Imagens só decorativas têm `alt=""`, para o leitor de tela ignorá-las.

## Resultado obtido

O axe encontrou 2 imagens sem o atributo `alt` em cada tela, entre elas o logo do cabeçalho:

```
#nava > img[src="blazemeter-favicon-512x512.png"]
```

Sem o `alt`, o leitor de tela anuncia o nome do arquivo ou só "imagem", e a pessoa cega não sabe o que é aquele elemento.

## Sugestão de correção

Adicionar `alt` às imagens do cabeçalho. Se o texto "PRODUCT STORE" já está ao lado do logo, a imagem pode receber `alt=""`, para não ser lida duas vezes.
