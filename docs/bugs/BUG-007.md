# BUG-007: Mensagem de contato sem limite de caracteres

| Campo | Valor |
|---|---|
| Prioridade | Baixa |
| Status | Aberto |
| Módulo | Contato |
| Ambiente | demoblaze.com, Chrome |
| Caso de teste | CT-4.3 / T10 |

## Passos para reproduzir

1. Abrir **Contact**.
2. Digitar uma mensagem com mais de 500 caracteres.
3. Clicar em **Send message**.

## Resultado esperado

Mensagem recusada com o aviso "A mensagem não pode exceder 500 caracteres" (limite da especificação).

## Resultado obtido

A mensagem é enviada, sem nenhum limite.


## Sugestão de correção

Adicionar `maxlength="500"` no campo e validar também no servidor.
