# BUG-005: Produto repetido vira uma nova linha no carrinho

| Campo | Valor |
|---|---|
| Prioridade | Média |
| Status | Aberto |
| Módulo | Carrinho |
| Ambiente | demoblaze.com, Chrome |
| Caso de teste | CT-2.4 / T04 |

## Passos para reproduzir

1. Adicionar **Samsung galaxy s6** ao carrinho.
2. Voltar e adicionar o mesmo produto de novo.
3. Abrir o carrinho.

## Resultado esperado

Uma única linha do produto com **quantidade 2** e o total atualizado.

## Resultado obtido

Duas linhas iguais do mesmo produto. Não existe campo de quantidade.


## Sugestão de correção

Agrupar itens iguais e exibir a quantidade, com botões para aumentar e diminuir.
