# BUG-002: Compra finalizada só com nome e cartão

| Campo | Valor |
|---|---|
| Prioridade | Alta |
| Status | Aberto |
| Módulo | Finalização de compra |
| Ambiente | demoblaze.com, Chrome |
| Caso de teste | CT-4.2 / T07 |

## Passos para reproduzir

1. Adicionar um produto ao carrinho.
2. Clicar em **Place Order**.
3. Preencher só **Name** e **Credit card**, deixando país, cidade, mês e ano em branco.
4. Clicar em **Purchase**.

## Resultado esperado

A compra é bloqueada e os campos obrigatórios em branco são destacados.

## Resultado obtido

A compra é confirmada normalmente.


## Sugestão de correção

Tornar país, cidade, mês e ano obrigatórios, já que são necessários para entrega e cobrança.
